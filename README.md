# AgriStock ERP

Production-oriented Fertilizer Shop ERP for Pakistan.

## Current Scope
This repository currently implements **PHASE 1**:
- Project setup (React + TypeScript + Vite)
- Tailwind + shadcn/ui-ready configuration
- Supabase client/auth foundation
- PostgreSQL schema, RLS, helper functions, and RPCs
- Demo seed data
- Setup and database documentation in `/docs`

## Quick Start
```bash
npm install
cp .env.local.example .env.local
npm run dev
```

See `docs/DEVELOPMENT_GUIDE.md` for migration and validation steps.
